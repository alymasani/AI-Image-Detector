## Evidence summary (runs of 2026-11-26, RTX 3080; threshold 0.5; 95% bootstrap CIs in brackets)

### Main results (`main_results.csv`, `statistics.json`)
| Model (seed 42) | Test set | Accuracy | AUROC | F1 | FPR | FNR |
|---|---|---|---|---|---|---|
| Custom CNN | SD 1.4 | 0.897 [0.888, 0.906] | 0.961 | 0.897 | 0.103 | 0.103 |
| Custom CNN | Midjourney | 0.514 [0.504, 0.524] | 0.465 [0.447, 0.483] | 0.212 | 0.103 | 0.869 |
| ResNet-18 | SD 1.4 | 0.963 [0.958, 0.969] | 0.994 | 0.963 | 0.041 | 0.033 |
| ResNet-18 | Midjourney | 0.608 [0.598, 0.619] | 0.727 [0.711, 0.742] | 0.396 | 0.041 | 0.743 |

- **Familiar generator:** ResNet-18 wins. Paired difference CNN − ResNet in accuracy is −6.6 pp [−7.6, −5.6], with exact
  McNemar p ≈ 7e-38.
- **Unseen generator:** both models collapse.
  - The CNN is at chance: its AUROC is *below* 0.5, so its score ranks Midjourney fakes as slightly more real than the
    real photos.
  - ResNet-18 keeps a weak but clearly-above-chance ranking signal (AUROC 0.727), yet at the 0.5 threshold it misses 74%
    of Midjourney fakes.
  - CNN − ResNet on Midjourney: accuracy −9.4 pp [−10.7, −8.2], AUROC −0.263 [−0.278, −0.247]; McNemar p ≈ 5e-52.

### Generalization drop, familiar → unseen (`generalization_drop.csv`, shared-real bootstrap)
| Model | Accuracy drop | AUROC drop |
|---|---|---|
| Custom CNN | 38.3 pp [37.3, 39.3] | 0.497 [0.480, 0.514] |
| ResNet-18 | 35.5 pp [34.4, 36.5] | 0.267 [0.252, 0.282] |

- The FPR is unchanged because the real photos are the same images. The whole drop is missed fakes (FNR +0.77 for the
  CNN, +0.71 for ResNet-18).
- `test_mj_native`, with Midjourney's own real photos, gives the same picture (CNN 0.511 / AUROC 0.469; ResNet 0.604 /
  0.722). The finding therefore does not depend on the shared-real protocol.

### Seeds (E7, `seed_repeatability.csv`, mean ± std over seeds 42/123/2026)
| Model | Test set | Accuracy | AUROC |
|---|---|---|---|
| CNN | SD 1.4 | 0.930 ± 0.029 | 0.980 ± 0.016 |
| CNN | Midjourney | 0.551 ± 0.032 | 0.565 ± 0.089 |
| ResNet-18 | SD 1.4 | 0.963 ± 0.001 | 0.995 ± 0.001 |
| ResNet-18 | Midjourney | 0.606 ± 0.006 | 0.721 ± 0.010 |

- The CNN is **much less stable across seeds**. The seed-42 primary run is its weakest on SD, because it early-stopped
  at epoch 12 on a noisy validation curve.
- Bootstrap CIs do not capture this training variance. In the report, use the seed spread when comparing models.
- The ranking (ResNet-18 > CNN on both test sets) holds for every seed.

### JPEG robustness (E3, `jpeg_robustness.csv`): extra JPEG on the standardised test images
- **SD 1.4 accuracy at q = 90 / 75 / 50:**
  - CNN: 0.887 / 0.877 / 0.872
  - ResNet-18: 0.945 / 0.935 / 0.880
- **Midjourney AUROC:** ResNet-18 falls 0.727 → 0.589 at q50.
- **FPR barely moves:**
  - CNN: 0.103 clean → 0.066–0.107
  - ResNet-18: 0.041 clean → 0.021–0.031

  Recompression mostly causes *missed fakes*, not false accusations of real photos. ResNet's FNR on SD rises from 0.033 to 0.211 at q50.

### Metadata shortcut (`metadata_baseline.csv`)
- Raw-file metadata separates the classes perfectly (AUROC 1.000).
- After standardisation, the file-size baseline is 0.554 on test_sd and 0.289 on test_mj.

### Compute (`computational_comparison.csv`, RTX 3080, fp16 AMP, batch 32)
| Model | Parameters | Training time | Peak GPU memory | Latency (batch 32) |
|---|---|---|---|---|
| CNN | 1.19 M | 608 s (12 epochs) | 1.02 GB | 0.46 ms/img |
| ResNet-18 | 11.2 M | 372 s (11 epochs) | 0.56 GB | 0.27 ms/img |

ResNet-18 is *faster* despite having 9× the parameters: the CNN's first block runs 32-channel convolutions at full
224×224 resolution, while ResNet downsamples ×4 in its stem.

### Failure cases (E5; `failure_cases_*.csv`, grids in git-ignored `results/figures/local/`)
Qualitative look at the ResNet-18 / test_mj grid. Six images per row: anecdotal, not a measured pattern.
- **Most confident false positives** (real photos scored P(AI) ≈ 1.00): catalogue- or studio-style shots. Examples are
  greyscale objects, plain or grey backgrounds and isolated products (camera, teapot, glass pitcher, cocktail shaker).
- **Most confident false negatives** (Midjourney scored P(AI) ≈ 0.00): photorealistic nature and macro scenes
  (centipede, spider, artichoke on black) and clean white-background renders (ball, polar bear, illustrated
  submarines).

If the report uses this, verify it on more examples first. Do not publish the grids, because they contain dataset
images.

## Points the analysis should address (answer only with completed evidence)
Familiar vs unseen winner; which model drops more (with the shared-real CI); does pretraining help (caveat:
architecture + init confounded, ImageNet overlap); over/underfitting from training curves; JPEG robustness (FPR
changes especially); metadata baseline (shortcut availability); FP vs FN concerns; are differences larger than the
bootstrap CIs; compute trade-offs (params, hours, latency, and on what hardware).

## Newsroom considerations (always applicable)
False accusations of real photos (FPR) are costly for credibility; missed fakes (FNR) spread misinformation;
new generators shift the distribution (this project measures one such shift); social-media recompression (E3);
probabilities are uncalibrated; benchmark prevalence is 50% but newsroom prevalence differs, so precision will differ;
the tool is an assistive screen requiring human review and provenance checks; it can't prove authenticity.
Any operating threshold must be chosen on SD 1.4 validation predictions.
