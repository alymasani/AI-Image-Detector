# Architecture

## Code layout

| Module | Responsibility |
|---|---|
| `src/data/download.py` | Official acquisition instructions, disk check, layout check, generator-folder discovery |
| `src/data/create_splits.py` | Deterministic manifests, exact-duplicate exclusion, pHash near-duplicate report, leakage checks |
| `src/data/audit.py` | Dataset bias statistics and the metadata-only shortcut baseline |
| `src/data/preprocessing.py` | Shared preprocessing (RGB → resize/crop 224 → JPEG q95 → augment → normalise), cache |
| `src/data/dataset.py` | `ManifestImageDataset` (on-demand loading) and seeded `DataLoader` construction |
| `src/data/synthetic.py` | Synthetic GenImage-shaped fixtures for software tests only |
| `src/models/cnn.py` | **Model A: custom four-block CNN (original Group 38 work)** |
| `src/models/resnet18.py` | **Model B: reference ResNet-18 integration** (see "Collaborator integration") |
| `src/models/factory.py` | Builds a model from config; parameter counts; initialisation description |
| `src/training/` | Explicit training loop, early stopping, checkpoint save/resume |
| `src/evaluation/` | Metrics, bootstrap/McNemar statistics, JPEG robustness, figures |
| `src/train.py`, `src/evaluate.py`, `src/experiment.py` | CLI entry points |
| `scripts/` | `prepare_data.py`, `run_experiments.py`, `generate_report_assets.py`, `reproduce.py`, `hpc/train.slurm` |

Data flow: GenImage folders → `create_splits` → `manifests/*.csv` (shared by both models) → `ManifestImageDataset`
→ model → `best.pt` (selected on SD 1.4 validation loss) → `evaluate` → `results/predictions/*.csv` +
`results/summaries/eval_*.json` → `generate_report_assets` → `results/tables`, `results/figures`.

Shared model interface: `logits = model(images)`, images `N×3×224×224` (ImageNet-normalised), logits `N×2`.
Label convention: **0 = real photograph, 1 = AI-generated (positive class)**.

## Model A: custom four-block CNN (trained from scratch)

Exact table (generated by `generate_report_assets.py` into `results/tables/cnn_architecture.csv`):

| Stage | Layers | Output | Parameters |
|---|---|---|---|
| Block 1 | 2×[Conv3×3-BN-ReLU] + MaxPool2×2 | 32×112×112 | 10,208 |
| Block 2 | 2×[Conv3×3-BN-ReLU] + MaxPool2×2 | 64×56×56 | 55,552 |
| Block 3 | 2×[Conv3×3-BN-ReLU] + MaxPool2×2 | 128×28×28 | 221,696 |
| Block 4 | 2×[Conv3×3-BN-ReLU] + MaxPool2×2 | 256×14×14 | 885,760 |
| Global average pool | AdaptiveAvgPool2d(1) | 256 | 0 |
| Head | Linear(256,64)-ReLU-Dropout(0.3)-Linear(64,2) | 2 logits | 16,578 |
| **Total** | | | **1,189,794** (all trainable) |

Initialisation: Kaiming-normal (fan_out, ReLU) for convolutions; BatchNorm γ=1, β=0; Kaiming-uniform for
Linear(256,64); Xavier-uniform for the logits layer; all biases 0. Convolutions have no bias because the following
BatchNorm supplies the shift.

Design rationale:
- **What blocks learn.** Block 1 sees 3–5 px neighbourhoods: colour/edge statistics, local noise and resampling
  traces. Later blocks combine them into larger textures (Block 4's receptive field covers most of the 224 px input),
  i.e. increasingly semantic/structural patterns.
- **Channels increase while resolution decreases.** Each pooling step quarters the spatial positions; doubling channels
  keeps compute per block roughly balanced and gives deeper layers more feature types to describe richer patterns.
- **BatchNorm** stabilises activations so a from-scratch network trains reliably at lr 1e-3 with Adam.
- **ReLU** is cheap and doesn't saturate for positive inputs, which keeps gradients alive through 8 conv layers.
- **Max pooling** gives cheap downsampling and small translation tolerance while keeping the strongest responses.
- **Global average pooling** instead of flattening 256×14×14 = 50,176 features avoids a ~3.2 M-parameter dense layer
  (more than the whole network), reduces overfitting and summarises artefacts that occur anywhere in the image.
- **Dropout 0.3** regularises the small head.
- **Two logits + cross-entropy.** `CrossEntropyLoss` applies log-softmax to the two logits internally (numerically
  stable); `softmax(logits)[:, 1]` is the AI probability used for thresholds and AUROC. No softmax/sigmoid in the model.
- **From scratch.** No pretrained weights, no torchvision model components, no residual connections (tested in
  `tests/essential/test_models.py`).
- **Limitation.** Resizing to 224 px and four pooling stages discard high-frequency information where some generator
  artefacts (e.g. upsampling periodicities) live. This trades forensic sensitivity for the proposal's fixed input size.

## Model B: ResNet-18 (ImageNet pretrained, fully fine-tuned)

`torchvision.models.resnet18(weights=ResNet18_Weights.IMAGENET1K_V1)`, `fc` replaced by `Linear(512, 2)`
(Xavier init), all 11,177,538 parameters trainable (`freeze_backbone: false`). If pretrained weights can't be
loaded, construction **fails** rather than silently using random weights. `model.pretrained=false` is the explicit
switch for the optional from-scratch control (E8).

### Collaborator integration

The ResNet-18 model is assigned to another group member. When this repository was set up (2026-11-25) there was no
collaborator code or checkpoint on any branch (`git fetch --all`: only `main` with the initial commit). So
`src/models/resnet18.py` is a **reference implementation** written to keep the pipeline executable. To integrate the
collaborator's work:
1. Add their module under `src/models/` (keep it unmodified where possible) and register it in `factory.py`.
2. Confirm: ImageNet weights? all layers trainable? label mapping (must be 0 = real, 1 = AI, or remap)? preprocessing
   (must match `src/data/preprocessing.py`)?
3. Train with the same manifests, or evaluate their checkpoint with `python -m src.evaluate` after converting it to
   this repo's checkpoint format (`model_state` + `model_config`).
4. Update `docs/ATTRIBUTION.md` and the contribution log.

## Scientific limitations of the comparison
- The two models differ in **both** architecture (8-conv plain CNN vs 18-layer residual network, 1.19 M vs 11.18 M
  parameters) and initialisation (scratch vs ImageNet). A difference can't be attributed to transfer learning alone;
  the optional E8 (ResNet-18 from scratch) separates the two factors.
- GenImage's real images **are ImageNet images**, and the ResNet-18 weights were trained on ImageNet-1k. The pretrained
  model may have seen some of the very same real photographs (train-partition reals come from the ImageNet training
  set). That familiarity could help it on the real class.
- Learning rates differ by design (1e-3 scratch, 1e-4 fine-tuning, the conventional choices) and are only tuned on
  SD 1.4 validation data.
